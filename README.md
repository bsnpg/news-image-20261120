**One page that sums up Friday 20 November 2026.** A newspaper front page drawn
in code: 36 stories across 7 regions, led by the Russian missile strike on
Kyiv's bridges, Cyclone Akvan's landfall in Odisha, and the AI sell-off that
sank Asia's markets — with a world map, a briefs list, and a date check that
leaves Thursday's news out. Every story is attributed to its source, and the
image is drawn with Python's Pillow library (see `make_image.py`).

## Run it

```sh
python3 main.py
```

The program copies `entry.png` to `/output/entry.png` (or
`$MAKEFUN_OUTPUT_DIR/entry.png` outside the grader). To redraw the image from
scratch:

```sh
python3 make_image.py
```
